# GUANE BioRxav project

Current author-review package: **submission-mammals/**. Start with submission-mammals/README_FIRST.md and manuscript/MANUSCRIPT_REVIEW.pdf inside it.

The 49-species mammal example replaces the finch illustration in the current manuscript. The package includes actual GUI execution evidence and exports, clean terminal replication, all 49 omission fits, two main figures, scripts, metadata fields and a written December 8, 2026 schedule. Nothing has been submitted, shared publicly or sent.

From submission-mammals run: Rscript --vanilla reproduce/run_all.R

Earlier finch files and review ZIPs are historical records only; do not mix their outputs with the current paper. Original GUANE source, examples, website documentation and the separate MEE manuscript are unchanged.
